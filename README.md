# 👥 HR Analytics Dashboard

## 📌 Project Title

# HR Analytics Dashboard: Employee Attrition & Workforce Insights

An interactive Power BI dashboard designed to analyze employee attrition, workforce demographics, job satisfaction, compensation, and employee performance metrics. The dashboard helps HR teams and business leaders identify key factors influencing employee turnover and improve workforce retention strategies.

---

## 📖 Short Description / Purpose

The HR Analytics Dashboard provides comprehensive insights into employee attrition patterns across departments, job roles, age groups, salary bands, and other workforce dimensions. It enables HR professionals to make data-driven decisions related to employee retention, workforce planning, and organizational performance.

---

## 🛠️ Tech Stack

The dashboard was built using the following tools and technologies:

* 📊 **Power BI Desktop** – Main data visualization platform used for report creation.
* 📂 **Power Query** – Data cleaning, transformation, and preparation.
* 🧠 **DAX (Data Analysis Expressions)** – Used for KPIs, calculated columns, and dynamic measures.
* 🔗 **Data Modeling** – Relationships and aggregations to support cross-filtering and interactive analysis.
* 📁 **File Formats**

  * `.pbit` – Power BI Template
  * `.pbix` – Development File
  * `.png` – Dashboard Screenshots

## ✨ Features & Highlights

### 🔍 Business Problem

Employee attrition can significantly impact organizational productivity, recruitment costs, and business continuity.

HR departments often struggle to answer questions such as:

* Which departments have the highest attrition?
* Which age groups are leaving the organization most frequently?
* Does overtime contribute to employee turnover?
* How does salary affect employee retention?
* Which job roles require immediate retention strategies?

Without centralized analytics, identifying these trends becomes difficult and time-consuming.

---

### 🎯 Goal of the Dashboard

The dashboard aims to:

* Monitor employee attrition trends.
* Identify workforce segments at risk of leaving.
* Analyze the impact of salary, job satisfaction, and work-life balance.
* Support HR decision-making through interactive visualizations.
* Improve employee retention and workforce planning.
